A program that draws a 1024x1024 newspaper front page summing up Sunday 22 November 2026's world news: the Gulf crisis (Iran strikes a US base in Kuwait as tankers burn off Oman), the COP31 climate talks deadlocked over fossil fuels, a magnitude 6.9 earthquake in Peru, Russia's 400-drone barrage on Ukraine, and the Trump–Xi–Putin summit in Shenzhen. Pure Python 3.13 stdlib — it draws every pixel itself with a small built-in bitmap font and a hand-written PNG encoder, so it runs with no network and writes byte-identical output on every run.

## Run it

```sh
python3 main.py
```
